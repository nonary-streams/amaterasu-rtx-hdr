# RTX HDR signed catalog

This catalog contains the optional Linux session package for RTX HDR. It is signed with the existing Amaterasu installation key identified by fingerprint `c412da5820e37e24d2bf0fc5bf6f9cb370810c01f6e59a1bc44e6b8c4f3222aa`. That key is a local-development identity; other installations will only accept this catalog if they independently trust the same signer.

NVIDIA runtime files are not included. The optional installer downloads and verifies them separately. This catalog expires on 2027-02-01 UTC and must be replaced with a higher catalog sequence before then.
